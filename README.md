# FitLog — Workout Library

FitLog is a responsive workout discovery and planning app built for focused strength training. Browse lifts, inspect their exercise details, and build a compact plan for the day.

## Technologies

- Next.js 15 with the App Router
- React 19 and TypeScript
- Custom responsive CSS
- FitLog REST API
- Browser localStorage for persistent training lists

## Features

- Live workout library with loading state and sortable duration, calories, and rating views
- Responsive gym-inspired dark UI for mobile, tablet, and desktop
- Individual workout detail pages with specs and instructions
- Today’s Plan and Saved lists with live navigation counters
- Five-lift daily cap, mark-as-done, remove actions, and toast feedback
- 404 route handling and deployment-friendly Next.js routing
